🔐 Test JWT Authentication

📌 Hướng dẫn:

1. Nhập Server URL (ví dụ: http://localhost:5xxx)

2. Đăng ký tài khoản Admin & Customer

3. Đăng nhập để lấy JWT token

4. Test các endpoint với token

⚙️ Cấu hình Server

⚠️ Luôn dùng URL HTTPS (không dùng cổng HTTP 5xxx). App có UseHttpsRedirection() nên khi gọi qua HTTP, trình duyệt sẽ tự follow redirect sang HTTPS và bị strip header Authorization → lỗi 401 giả.

🔑 Đăng nhập / Đăng ký

⚠️ Đăng ký luôn gán Role = Customer. Muốn thành Employee/Admin, hãy đăng nhập bằng tài khoản Admin và dùng panel "API tuỳ chỉnh" bên dưới để gọi PUT /api/users/{id}/role.
